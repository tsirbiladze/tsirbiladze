### Tornike Sirbiladze

Full-stack developer in Tbilisi, Georgia. For six years I've built business software:
clinic and point-of-sale systems, checkout, bank payment gateways and subscriptions,
mostly in TypeScript, React/Next.js, Node.js and PHP/Laravel. Most of that code belongs
to clients and is private.

Over the past year I've focused on AI integration. What I publish here:

- **[logisticshub](https://github.com/tsirbiladze/logisticshub)** cross-checks an invoice,
  packing list, CMR and contract. The model only reads the documents; 16 deterministic
  rules do the checking, and every finding cites the exact quote and page.
  Agent skill, CLI and MCP server.
- **[sitewright](https://github.com/tsirbiladze/sitewright)** is an agent skill that builds
  a personal site from a Next.js template and takes it live on Vercel.
- **[clear-writing-skills](https://github.com/tsirbiladze/clear-writing-skills)** teaches
  coding agents to write clear Georgian and English.

I build these with coding agents that work from written specs. I design, review and test,
and each README says what has been verified and what hasn't.
